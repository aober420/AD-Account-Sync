AD Account Sync

Uses the LDAP server, bind account, Base DN, and TLS settings from LDAP-Auth.

Usually sAMAccountName; it must match the user names LDAP-Auth creates.
The disabled-account condition is added automatically. Default: (objectCategory=person).
Leave this off unless matching non-LDAP-Auth accounts should also be disabled.
On by default. Any matching disabled Jellyfin account is re-enabled after AD confirms the account is enabled.
